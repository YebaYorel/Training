# Dépose ici l'export Stitch

Exporte le projet en HTML/CSS ou Tailwind depuis Stitch, puis dépose les
fichiers dans ce dossier. L'audit de sécurité du code pourra alors être mené :
injections, formulaires, secrets exposés, dépendances, accessibilité du
balisage, performance.

Ce dossier est suivi par Git ; ne jamais y déposer de clé, de jeton ni de
fichier .env.
