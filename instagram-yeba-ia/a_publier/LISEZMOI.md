# Publications prêtes à poster : publiez dans l'ordre 01 → 09

Les images sont en pleine résolution (1080×1440 pour les posts, 1080×1920 pour les réels).
En publiant de 01 à 09, votre grille s'affichera exactement comme sur `visuels/maquette_profil.png`.

| N° | Type | Comment publier |
|---|---|---|
| 01 | Post | 1 image. Choisissez le format **3:4** (bouton de recadrage) |
| 02 | Post | 1 image, format 3:4 |
| 03 | Réel | `…_video.mp4` → « Modifier la couverture » → « Ajouter depuis la pellicule » → `…_couverture.png` |
| 04 | Carrousel | Sélectionnez les 7 slides **dans l'ordre** (1 → 7), format 3:4 |
| 05 | Réel | Comme le 03 |
| 06 | Post | 1 image, format 3:4 |
| 07 | Post | 1 image, format 3:4 |
| 08 | Réel | Comme le 03 |
| 09 | Post | 1 image, format 3:4 |

Pour les réels, ajoutez un son depuis la **bibliothèque audio d'Instagram** au moment de publier.
Les légendes, textes alternatifs et hashtags se trouvent dans `GUIDE_INSTAGRAM_YEBA_IA.md`, §4.
Avant de publier les numéros 04 et 08 (IA Act), vérifiez le statut du « Digital Omnibus » sur EUR-Lex.
