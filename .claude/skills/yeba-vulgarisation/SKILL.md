# Vulgariser sans trahir

Le niveau technique est **maximal sur le fond**, simple sur la forme. Vulgariser,
ce n'est pas simplifier à tort : chaque analogie doit rester **vraie** sur
l'essentiel, et on dit où elle s'arrête.

## 1. Méthode en 5 temps (inspirée de la technique de Feynman)

1. **Une phrase** : expliquer la notion comme à un client de 14 ans.
2. **Une analogie locale** (voir §2), puis « là où l'analogie s'arrête ».
3. **Un exemple saisissant** tiré d'une entreprise réunionnaise fictive mais
   crédible (hôtel de Saint-Gilles, quincaillerie du Tampon, BTP à Saint-Denis,
   restaurant de Saint-Pierre, exploitation de canne…).
4. **Le mot technique exact**, introduit seulement maintenant (mode symbolique
   de Bruner).
5. **La vérification** : une question que le stagiaire ne peut réussir que s'il a
   compris (pas récité).

## 2. Banque d'analogies (à enrichir)

| Notion | Analogie | Où elle s'arrête |
|---|---|---|
| API | Le serveur au restaurant : il prend la commande, la porte en cuisine, rapporte le plat | Une API a des règles strictes : une commande mal formulée est refusée |
| Workflow / automatisation | Une chaîne au marché forain : chacun fait une étape, toujours dans le même ordre | Le workflow ne s'adapte pas seul à l'imprévu : il faut prévoir les cas d'erreur |
| LLM (IA générative) | Un très bon élève qui a lu toute la bibliothèque et devine la suite la plus probable | Il ne « sait » pas : il peut inventer avec aplomb (hallucination) |
| Données personnelles (RGPD) | Le carnet d'adresses de la boutique : il appartient aux gens qui y figurent, pas à la boutique | Une donnée peut être personnelle même sans nom (plaque, IP, voix) |
| Chiffrement | Un coffre dont seul le destinataire a la clé | Si on perd la clé, personne ne peut rouvrir le coffre, même pas soi |
| IA Act, niveaux de risque | Le code de la route : vélo, voiture, poids lourd, matières dangereuses | Le risque dépend de l'usage, pas de l'outil |
| Hameçonnage (phishing) | Le faux agent EDF qui sonne à la porte | Par mail, le « faux agent » peut imiter parfaitement le logo |

## 3. Trois niveaux de lecture dans chaque support

| Niveau | Où | Contenu |
|---|---|---|
| 1. L'essentiel | diapo PowerPoint | 3 mots-clés + 1 visuel |
| 2. Comprendre | ressource PDF | explication + analogie + exemple |
| 3. Approfondir | encadré « Pour aller plus loin » du PDF | détail technique, références, textes de loi |

Chacun s'arrête où il veut, sans jamais être perdu.

## 4. Rendre ludique (« apprendre en s'amusant »)

Défi chronométré entre équipes, « vrai ou fake IA ? », escape game RGPD
(trouver les 5 fuites de données dans un bureau fictif), jeu de rôle client /
prestataire, quiz avec boîtiers ou à main levée. Toujours **débriefer** : le jeu
sans débriefing ne laisse rien.

## 5. Contrôle qualité

- Aucune phrase de plus de 20 mots dans un support stagiaire.
- Tout sigle est expliqué à sa première apparition.
- Chaque notion technique a son analogie **et** son exemple.
- Pas de jargon anglais quand un mot français clair existe (sauf terme du métier,
  alors on le traduit).
