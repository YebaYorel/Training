# Plaquette commerciale YEBA FORMATIONS 2026

| Fichier | Usage |
|---|---|
| `plaquette-yeba-2026.pdf` | **Pièce jointe** des mails de prospection (A4 portrait, 2 pages, 0,75 Mo) |
| `plaquette-yeba-2026-p1.png` / `-p2.png` | Aperçus en image (LinkedIn, WhatsApp, impression) |
| `plaquette-yeba-2026-animee.mp4` | Version animée, 31 s, 1080 × 1350 (format 4:5), sans son : LinkedIn, WhatsApp, écran de salon, rendez-vous |
| `plaquette-yeba-2026-mail.gif` | Mini-animation de 8 s (1,3 Mo) à insérer **dans le corps** d'un mail |
| `plaquette-yeba-2026-vignette-mail.jpg` | Image fixe légère (80 Ko) si le GIF est trop lourd pour le destinataire |
| `*.html` | Sources modifiables : changer un texte, puis régénérer le PDF ou la vidéo |

## Règle d'envoi
1. Dans le corps du mail : la **vignette** ou le **GIF**, cliquable vers votre site ou vers la vidéo hébergée.
2. En pièce jointe : le **PDF** uniquement. Ne joignez jamais le MP4 : il pèse 5 Mo et beaucoup de messageries d'entreprise le bloquent.
3. Le MP4 sert sur LinkedIn, sur WhatsApp, et sur un écran en rendez-vous ou en salon.
