## Mode d'emploi avant chaque envoi

1. **Vérifier** tout ce qui est marqué **[À VÉRIFIER]** (appel au standard : nom, fonction, adresse email). Ne jamais envoyer un courriel avec un nom incertain.
2. **Compléter** : `[date 1]`, `[date 2]`, `[Téléphone]`, `[Adresse email]`, `[Site internet]`.
3. **Pièces jointes** : votre CV + la « note de proposition » = parties 2 à 8 du mémo, exportées en PDF (la partie 9, technique, reste interne).
4. **Envoyer un par un**, depuis l'adresse de votre domaine (SPF, DKIM et DMARC configurés : guide, étape 15), jamais en copie multiple.
5. **Relancer une seule fois** à J+7 par téléphone, puis noter le résultat dans le classeur (onglet « Acteurs », colonne Statut).
6. **Marque blanche** : si vous intervenez pour un autre organisme, retirez toute mention de YEBA FORMATIONS des supports.

## RGPD / IA Act — pour cette campagne

- **RGPD** : prospection B2B des décideurs, en lien avec leur fonction, sur la base de l'intérêt légitime. Chaque courriel contient la mention d'information (art. 14) et un moyen simple de s'opposer. Conservation : 3 ans après le dernier contact.
- **IA Act** : aucune des solutions proposées ne prend de décision sur des personnes (pas de tri de candidats, pas de notation, pas d'orientation automatisée) ; les usages publics (chatbots) affichent qu'il s'agit d'une IA (art. 50, applicable depuis le 02/08/2026).

## Autocritique et corrections

| Faille | Risque | Correction apportée |
|---|---|---|
| Plusieurs décideurs non confirmés | Courriel mal adressé, crédibilité | Mention [À VÉRIFIER] + étape 1 du mode d'emploi |
| Courriels ressemblants pour des structures proches (intercommunalités, OPCO) | Impression de mailing de masse si les destinataires se parlent | Personnalisez au minimum la première phrase avec un fait propre à la structure |
| Promesse de résultats (taux de sortie, cas d'usage à J+60) | Engagement difficile à tenir | Les objectifs sont « à fixer avec vous », jamais garantis |
| Prix des outils issus en partie de sources tierces | Devis faux | Prix indiqués comme indicatifs, à reconfirmer au moment du devis |
| Capacité (plus de 380 jours de missions au total) | Impossible pour une seule personne | Formateurs associés, groupement, priorisation (collectivités, puis Région et France Travail) |
| Hébergement de données sensibles (Département, Agefiph) | Non-conformité si VPS classique | Question SecNumCloud posée avant tout chiffrage ; données de santé jamais saisies dans une IA |
| Licence n8n | Litige si une instance mutualisée sert plusieurs clients | Une instance par client, sur son serveur ; Activepieces (MIT) en alternative |
| Albert (État) : conditions d'accès 2026 non confirmées | Proposition irréalisable | Mistral API en solution de repli dans chaque mémo |
| Version gratuite de Le Chat | Données utilisées pour l'entraînement | Interdite avec des données de travail, rappelée partout |
| Écologie | Serveurs surdimensionnés | Taille de VPS adaptée à l'usage ; transcription par API quand le volume est faible |
